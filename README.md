# Портфолио: автоматизация на Python

Два небольших проекта, показывающих типовые задачи для бизнеса. Все данные в примерах вымышлены. Каждый проект запускается отдельно и содержит код, тесты, пример входных данных и результат.

| Проект | Задача заказчика | Что получает заказчик |
| --- | --- | --- |
| [Очистка и объединение CSV](csv-cleaner/README.md) | Собрать выгрузки контактов из разных источников | Единый файл без повторов, список отклонённых строк и отчёт |
| [Отчёт по продажам в Excel](sales-report/README.md) | Превратить выгрузку заказов в понятные показатели | XLSX с итогами, разбивкой по дням и товарам, списком ошибок |

## Как показать заказчику

1. Отправить ссылку на подходящий проект и кратко описать, какую похожую задачу он решает.
2. Показать пример входного файла и готовый результат из `demo-output/`.
3. Уточнить формат данных заказчика и критерии готовности до оценки срока и цены.

Проекты можно разместить как один репозиторий-портфолио либо опубликовать в двух отдельных репозиториях. Для работы с реальными данными сначала создавайте копии файлов и не публикуйте их в GitHub.
