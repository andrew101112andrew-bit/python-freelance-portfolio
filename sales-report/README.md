# Отчёт по продажам в Excel

Демонстрационный проект: из простой выгрузки заказов создаётся Excel-книга с итогами, продажами по дням и товарам, списком корректных заказов и строками с ошибками. Все данные вымышлены.

## Входные данные

CSV в UTF-8 с колонками `order_id,date,product,quantity,unit_price`:

```csv
order_id,date,product,quantity,unit_price
A-1001,2026-09-01,Кружка,2,450.00
```

Дата — в формате `ГГГГ-ММ-ДД`, цена — в рублях с точкой в качестве десятичного разделителя. Повторный `order_id`, нулевое количество и некорректные значения попадают на лист «Ошибки». Суммы считаются через `Decimal`, чтобы избежать ошибок округления при сложении цен.

## Запуск

Нужен Python 3.10 или новее.

```bash
cd sales-report
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python report.py examples/orders.csv --out demo-output
python -m unittest discover -s tests -v
```

После запуска доступны [`report.xlsx`](demo-output/report.xlsx) и [`summary.json`](demo-output/summary.json). В книге пять листов: «Итоги», «По дням», «По товарам», «Заказы», «Ошибки». На листе «По дням» есть диаграмма.

## Что уточнить у реального заказчика

Состав колонок, валюту, порядок учёта возвратов, скидок и доставки, а также является ли один `order_id` одной строкой или заказ может содержать несколько товаров. Данная демонстрация использует одну строку на заказ и не учитывает возвраты.
