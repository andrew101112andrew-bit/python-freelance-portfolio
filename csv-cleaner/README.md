# Очистка и объединение CSV

Демонстрационный проект для ситуации, когда контакты приходят несколькими выгрузками с разными названиями колонок. Скрипт объединяет файлы, очищает пробелы, приводит адреса электронной почты к нижнему регистру и убирает повторы по адресу.

Поддерживаются CSV с разделителем `,` или `;` и кодировкой UTF-8. Названия колонок могут быть на русском или английском: `name`/`имя`, `email`/`почта`, `phone`/`телефон`, `company`/`компания`. Обязательна только колонка с электронной почтой.

## Запуск

Нужен Python 3.10 или новее. Дополнительные библиотеки не нужны.

```bash
cd csv-cleaner
python3 cleaner.py examples/contacts_a.csv examples/contacts_b.csv --out demo-output
python3 -m unittest discover -s tests -v
```

Скрипт создаёт:

- `cleaned.csv` — уникальные записи;
- `rejected.csv` — строки без корректной почты и дубликаты с причиной;
- `summary.json` — число прочитанных, сохранённых и отклонённых строк.

Готовый пример результата лежит в [`demo-output`](demo-output). Данные вымышлены, адреса используют домен `example.com`.

## Границы услуги

Пример рассчитан на стандартные CSV. Перед реальным заказом нужно согласовать названия колонок, правило выбора записи при дубликате и то, что считать корректным адресом. Скрипт проверяет обычный формат адреса, но не существование почтового ящика.
